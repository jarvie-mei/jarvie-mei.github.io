bitXnor

题目要求：

  • 只用~和|表示~(x^y)
  • 最大操作数：7

解题思路：

根据~(x ^ y)的定义，~(x ^ y) = (x & y) | (~x & ~y) 再根据德摩根定律，x & y = ~(~x | ~y)

解题代码：

int bitXnor(int x, int y) {
    return ~(~x | ~y) | ~(x | y);
}

bitConditional

题目要求

  • 对每个比特位分别执行 x ? y : z
  • 允许的操作符：& | ^ ~
  • 最大操作数：4

解题思路1

x某位为1,我们选择y对应的那一位。x某位为0,我们选择z对应的那一位。

解题代码1

int bitConditional(int x, int y, int z) {
    return (x & y) | (~x & z);
}

解题思路2

通过 y^z标记出y和z不同的位。利用的异或的性质，相同为0,不同为1。

y^z表示从z变成y有那些位需要翻转，(y ^ z) & x则表示只有当x位为1的时候，z要变成y。

最后z^((y ^z) & x),表示把z中需要翻转的位翻转过去。利用异或的性质 1 ^ a = ~a。

解题代码2

int bitConditional(int x, int y, int z) {
    return z ^ ((y ^ z) & x);
}

byteSwap

题目要求

  • 交换一个数的第n字节和第m字节
  • 假定 0 <= n <= 3, 0 <= m <=3
  • 允许的操作符：! ~ & ^ | + << >>
  • 最大操作数：16

解题思路1

把n字节和m字节的比特位提取出来，再把n字节和m字节清零，最后交换n字节m字节取或即可

解题代码1

int byteSwap(int x, int n, int m) {
    int clear_mask, byte_n, byte_m;
    n <<= 3, m <<= 3;
    clear_mask = ~((0xFF << n) | (0xFF << m));
    byte_n = (x >> n) & 0xFF
    byte_m = (x >> m) & 0xFF

    return (x & clear_mask) | (byte_n << m) | (byte_m << n); 
}

解题思路2

我们知道 t = a ^ b，则 a ^ t = b, b ^ t = a

据此我们可以先让m字节和n字节进行异或，然后让第m字节异或这个结果就变成第n字节。

int byteSwap(int x, int n, int m) {
    n <<= 3, m <<= 3;
    int t = ((x >> m) ^ (x >> n)) & 0xFF;
    return x ^ (t << m) ^ (t << n);
}

logicalShift

题目要求

  • 将x逻辑右移n位
  • 允许的操作符：! ~ & ^ | + << >>
  • 最大操作数：16

解题思路

我们知道，正数进行算术右移与逻辑右移是一样的，关键是负数。 不论正负数，我们只需把算术右移的结果的高n位清零即可。

解题代码

int logicalShift(int x, int n) {
    return ~(1 << 31 >> n << 1) & (x >> n);
}

cleanConsecutive1

题目要求

  • 将x的位表示中的任何连续1,都清零。
  • 允许的操作符：! ~ & ^ | + << >>
  • 最大操作数：16

解题思路1

通过逻辑右移一位与左移一位，我们将对应位的左右邻居都表示出来。

我们令x左移一位得到的位表示为y，逻辑右移一位得到的位表示为z

yi=1y_i = 1yi​=1说明xi−1=1x_{i-1} = 1xi−1​=1。 zi=1z_i = 1zi​=1说明xi+1=1x_{i+1} = 1xi+1​=1

若(xi=1∧yi=1)∨(xi=1∧zi=1)(x_i = 1 \land y_i = 1) \lor (x_i = 1 \land z_i = 1)(xi​=1∧yi​=1)∨(xi​=1∧zi​=1)则xix_ixi​需要清零。

用代码表示即

int y = x << 1;
int z = (x >> 1) & ~(1 << 31);
int result = x & ~(y | z);

解题思路2

int t = x & (x << 1);

这标记了当前位和右侧位都为1的位。即 ti=1t_i = 1ti​=1 则 xi=1∧xi−1=1x_i = 1 \land x_{i-1} = 1xi​=1∧xi−1​=1

int s = t >> 1;

这标记了当前位和左侧位都为1的位。即si=1s_i = 1si​=1 则 xi=1∧xi+1=1x_i = 1 \land x_{i + 1} = 1xi​=1∧xi+1​=1

因为 si=1s_i = 1si​=1 则ti+1=1t_{i+1} = 1ti+1​=1 则 xi+1=1∧xi=1x_{i+1} = 1 \land x_{i} = 1xi+1​=1∧xi​=1

这里为什么不用考虑t最高位为1，进行算术右移前面补了1的影响？因为t的最高位如果是1,已经说明了x的最高位和次高位为1。 此时的x最高位是需要清零的，s的最高位为1只是重复标记了需要清零的位，对结果没有影响。

解题代码

int cleanConsecutive1(int x){
    int right_mask = x & (x << 1); // Identify positions that current and right bits are both 1
    int left_mask = right_mask >> 1; // Identify positions that current and left bits are both 1
    int consecutive_mask = right_mask | left_mask; // Combine both masks to get all positions
    return x ^ consecutive_mask; // Flip the bits at those positions to 0 

    // another way to implement this function is to use the following code:
    // int right_mask = x << 1; // right neighbor of the i-th bit
    // int left_mask = x >> 1 & ~(1 << 31); // left neighbor of the i-th bit
    // return x & ~(right_mask | left_mask); // when the i-th bit is 1 and its left or right neighbor is 1, then it is a consecutive 1, we need to flip it to 0
}

leftBitCount

题目要求

  • 计算从最高位开始的连续1的数量
  • 允许的操作符：! ~ & ^ | + << >>
  • 最大操作数：50

解题思路

判断是否是连续的1有点难度，假设我们要计算11110001211110001_2111100012​的最高位开始连续1的个数。我们对其做右移操作，右移 4位，如果是算术右移，前面又被补了1。即使是逻辑右移，你也得不到能判断其为连续1的有用信息。但是，如果我们要判断连续0的个数， 就变得很简单了。所以我们先对需要判断的数取反。

我们采用二分法来判断连续0的个数。

先将其右移16位，如果右移16位得到的结果为0,则连续0至少有16个，再看低16位的情况。如果结果非0,那么连续的0一定在高16位。只需考虑高16位即可。 同样，对我们得到的低16位或高16位的前8位进行分析。以此类推，这样我们能判断16+8+4+2+1=31位，最后再判断最后一位是不是0就可以了。

int leftBitCount(int x) {
    int count = 0;
    int t;
    x = ~x; // It's easier to count leading zeros, because !0 is 1, but !x when x is not 0 always equal to 0, which makes it hard when shifting right some bits to determine if it is all ones or not.
            // But zeros can be easily determined by shifting right some bits and check if it is 0 or not.
    t = !(x >> 16) << 4;
    x <<= t;
    count += t;

    t = !(x >> 24) << 3;
    x <<= t;
    count += t;

    t = !(x >> 28) << 2;
    x <<= t;
    count += t;

    t = !(x >> 30) << 1;
    x <<= t;
    count += t;

    t = !(x >> 31);
    count += t;
    x <<= t;

    t = !(x >> 31);
    count += t;

    return count;
}

counter1To5

题目要求

  • 返回 1+x 如果 x < 5， 其他情况返回1
  • 题目确保了 1 <= x <= 5
  • 允许的操作符：~ & ! | + << >>
  • 最大操作数：15

解题思路

怎么判断x是否为5？

我们可以通过x-5是否等于0来判断

int isFive = !(x + ~5 + 1)

按照题目要求，如果x是5返回1,否则返回x+1。

意思就是x = 5, 返回 1 + x + (-x)， 否则 返回 1 + x + 0 -5 = ~4,只需x=5返回1 + 5 + （~4），否则 返回 1 + x + 0。

我们需要一个0x00000000与0xFFFFFFFF的mask

int mask = ~isFive + 1 //x为5时mask是0,x非5时mask是-1即0xFFFFFFFF

解题代码

int counter1To5(int x) {
    int isFive = !(x + ~5 + 1);
    int mask = ~isFive + 1; // mask is 0xFFFFFFFF if x == 5, otherwise it is 0x00000000
    return x + 1 + (mask & ~4); // ~4 = -5, if x == 5, then return 1, otherwise return x + 1
}

satMul3

题目要求

  • 将一个整数*3, 如果溢出，向下/上取到TMax 或 Tmin
  • 允许的操作符： ! ~ & ^ | + << >>
  • 最大操作数： 25

解题思路

首先，我们思考怎么在位运算中计算出x*3:

int x2 = x + x; // 或者 x << 1
int x3 = x2 + x;

如果没有溢出，则x，x2，x3的符号位应该都相同 我们可以用(a ^ b) >> 31来标记a, b两数的符号位是否相同，相同则为0x00000000，不同则为0xffffffff 而符号位不同就代表已经发生溢出了。所以我们同样可以用0xffffffff, 0x00000000来标记是否溢出。

int overflow = ((x ^ x2) | (x ^ x3)) >> 31;

为什么不是overflow &= 1;，用0和1来标记是否溢出呢？

因为，我们在翻译下面的逻辑代码的时候，方便做等价转换。

 if (overflow) {
    return sat; //sat = TMAX or TMIN.
 } else {
    return x3;
 }

这个判断在位运算里可以等价翻译成：

(overflow & sat) | (~overflow & x3)

关键这个sat要怎么求？ 我们知道，sat的值和x的正负有关，x为正， 3x也为正，那么溢出后应该返回Tmax， 那我们不如就引入一个sign标记。

int sign = x >> 31; //x >0, sign = 0x00000000; x < 0 sign = 0xffffffff

我们先观察，

if sign = 0x00000000 -> sat = Tmax = 0x7fffffff
if sign = 0xffffffff -> sat = Tmin = 0x80000000

我们观察到，Tmin = ~Tmax

而异或Xor有个特性：

0 ^ A = A
0xffffffff ^ A = ~A

所以如果我们让 sat = sign ^ Tmax 那么当

x > 0:
sign = 0x00000000
sign ^ Tmax = 0 ^ Tmax = Tmax

x < 0:
sign = 0xffffffff
sign ^ Tmax = ~Tmax = Tmin

所以sat可以用 sign ^ Tmax来表示。 至此我们就可以写出解题代码了。

解题代码

int satMul3(int x) {
    int x2 = x << 1;
    int x3 = x2 + x;
    int Tmin = 1 << 31;
    int Tmax = ~Tmin;
    int sign = x >> 31;
    int overflow = ((x ^ x2) | (x ^ x3)) >> 31;
    int sat = sign ^ Tmax;
    return (overflow & sat) | (~overflow & x3);
}

isGreater

题目要求

  • 如果 x > y，则返回1,否则返回0
  • 允许的操作符：! ~ & ^ | + << >>
  • 最大操作数：24

解题思路

如果x和y最高位不同，则当x最高位为0时返回1。x和y最高位相同，则直接相减来判断。

int isGreater(int x, int y) {
    int sx = (x >> 31) & 1;
    int sy = (y >> 31) & 1;
    int signDiff = sx ^ sy;

    int diff = x + ~y + 1;

    int diffSign = (diff >> 31) & 1;


    return (signDiff & !sx) | (!signDiff & !diffSign & !!diff); //符号位不同且x符号位为0 或 符号位相同且差的符号位为0,且差不为0
}

subOK

题目要求

  • 判断计算x-y是否产生溢出
  • 允许的操作符：! ~ & ^ | + << >>
  • 最大操作数：20

解题思路

x与y符号位相同，相减肯定不会溢出。x与y符号位相异，若 x 符号位为0 , 结果符号位为1,则溢出。若x符号位为1,结构符号位为0,则溢出。

int subOK(int x, int y) {
    int sx = (x >> 31) & 1;
    int sy = (y >> 31) & 1;
    int diff = x + ~y + 1;
    int diffSign = (diff >> 31) & 1;
    int overflow = (sx ^ sy) & (sx ^ diffSign);

    return !overflow; 
}

trueFiveEights

题目要求

  • 计算58x\frac{5}{8}x85​x，向零舍入
  • 允许的操作符：!、~、&、^、|、+、<<、>>
  • 最大操作次数：25

解题思路

对于正数，算术右移向下取整正好也是向零取整，所以不需要加bias。

对于负数，算术右移要修正为向零取整，则得加一个bias，这个bias大小为 2k−12^k - 12k−1 其中 kkk为算术右移的位数。

在本题中，对应的bias就是7。

设x=8q+rx = 8q + rx=8q+r

若 x>0x > 0x>0 则 x >> 3 = ⌊x/8⌋ \left\lfloor x/8 \right\rfloor⌊x/8⌋

若 x<0x < 0x<0 则 (x + 7) >> 3 = ⌈x/8⌉\left\lceil x / 8 \right\rceil⌈x/8⌉

  1. x<0x < 0x<0:
⌈5x/8⌉=⌊(5x+7)/8⌋=⌊(5(8q+r)+7)/8⌋=⌊5q+(5r+7)/8⌋=5q+⌊(5r+7)/8⌋\begin{aligned} \left\lceil 5x/8 \right\rceil &= \left\lfloor (5x + 7) / 8 \right\rfloor \\ &= \left\lfloor (5(8q + r) + 7) /8 \right\rfloor \\ &= \left\lfloor 5q + (5r+7) / 8 \right\rfloor \\ &= 5q + \left\lfloor (5r + 7) / 8 \right\rfloor \end{aligned}⌈5x/8⌉​=⌊(5x+7)/8⌋=⌊(5(8q+r)+7)/8⌋=⌊5q+(5r+7)/8⌋=5q+⌊(5r+7)/8⌋​

所以，要实现负数向零取整 对应代码为：

int q = x >> 3, r = x & 7;
int q5 = (q << 2) + q;
int r5 = (r << 2) + r;

int result = q5 + (r5 + 7) >> 3;
  1. x>0x > 0x>0: 类似的推导可以得到：
result = q5 + r5 >> 3

所以，整合起来，只需在x < 0 时，加上bias即可。

解题代码

int trueFiveEighths(int x) {
    int q = x >> 3, r = x & 7;
    int q5 = (q << 2) + q;
    int r5 = (r << 2) + r;

    int bias = (x >> 31) & 7;

    return q5 + (((r5 + bias)) >> 3);

}

float_half

题目要求

  • 计算浮点数 f 的 12f\frac{1}{2}f21​f 位级等效值，但是如果 f 是 NaN，直接返回 f
  • 允许的操作符： 任何整数/无符号整数操作，包括 ||, &&，也包括条件语句if和循环语句while。
  • 最大操作数：30

解题思路

首先，我们来回顾一下IEEE 754浮点数的表示方法，如下图所示：1

对于单精度浮点数(float)，有：

  • 符号位：1位
  • 指数位：8位，偏移量27−1=1272^7 - 1 = 12727−1=127，对于非规格化数，其指数位全为0,指数为21−bias=2−1262^{1-bias} = 2^{-126}21−bias=2−126， 对于规格化数，其指数位不全为0,指数为2e−bias2^{e-bias}2e−bias，其中eee为指数位的值
  • 尾数位：23位，对于非规格化数，尾数为0.f0.f0.f，对于规格化数，尾数为1.f1.f1.f

对于双精度浮点数(double),有：

  • 符号位：1位
  • 指数位：11位，偏移量210−1=10232^10-1 = 1023210−1=1023，对于非规格化数，其指数位全为0，指数位21−bias=2−10222^{1-bias} = 2^{-1022}21−bias=2−1022，且 对于规格化数，其指数位不全为0，指数位2e−bias2^{e-bias}2e−bias，其中eee为指数位的值
  • 尾数位：52位，对于非规格化数，尾数为0.f0.f0.f，对于规格化数，尾数为1.f1.f1.f

我们回到题目：

  1. 非规格化数： 非规格化数除以2,相当于将尾数右移一位。这个时候，尾数变成24位了，必然需要进行舍入。按照标准的浮点数舍入方法：round-to-even 四舍六入五取偶。我们看尾数后两位有四种情况：
  • 0.YYYY...YYY00(Y是0或者1)：右移正好整除，是精确值，不需要舍入。
  • 0.YYYY...YYY01：右移后为0.0YYYY...YYY01,需要舍入的位已经是0,向偶舍入直接抛弃最后一个1即可。
  • 0.YYYY...YYY10：右移也整除，不需要舍入。
  • 0.YYYY...YYY11：右移后为0.0YYYY...YYY11,需要舍入的位为1,向偶舍入，需要加1。使得舍入的位变成0。

由此我们得出，只有当尾数最低两位为11时，右移后需要加一个round:1。那么怎么构造这个round呢？

int round = !((uf & 0x3) ^ 3)
  1. 规格化数： 规格化数除以2，我们自然想到，把指数位减去1即可。但是如果指数位正好是1,减去一变成非规格化数了。我们分两种情况
  • 指数位为1 我们知道规格化数的尾数M其实是1.f1.f1.f向右移一位应该变成0.1f0.1f0.1f，正好我们可以借指数位的1一起右移就得到想要的结果， 因为变成非规格化数后，阶数并没有发生变化还是-126。同样也需要判断是否需要舍入，舍入规则和非规格化数一样。
  • 指数位非1 只需将指数减1即可
  1. NaN和−∞,+∞-\infty,+\infty−∞,+∞ 直接原封不动返回即可。

解题代码

unsigned float_half(unsigned uf) {
    int sign_mask = 0x80000000, exp_mask = 0x7f800000, frac_mask = 0x007fffff;
    int sign = uf & sign_mask, exp = uf & exp_mask, frac = uf & frac_mask, round = !((uf & 3) ^ 3);
    if (!exp) {
        return sign | (((frac) >> 1) + round);
    }

    if (exp == exp_mask) {
        return uf;
    }

    if(exp >> 23 == 1) {
        return sign | (((exp | frac) >> 1) + round);
    }

    return sign | (((exp >> 23) - 1) << 23) | frac;
}

float_i2f

题目要求

  • 将整数x转换为浮点数，相当于实现(float)x
  • 允许的操作符： 任何整数/无符号整数操作，包括 ||, &&，也包括条件语句if和循环语句while。
  • 最大操作数：30

解题思路

一个32位的有符号整数x，在浮点数的表示下，指数值最大是多少？

由于−231≤x≤231−1-2^{31} \le x \le 2^{31} - 1−231≤x≤231−1，为了方便，我们将Tmin和0单独考虑。如果x是负数，我们就取它的相反数。 这样我们只需要考虑正整数即可。首先，正整数肯定会被转换成规格化数，因为最大的非规格化数也小于1。我们令y=∣x∣y=\left|x\right|y=∣x∣， 其中，x不是Tmin也不是0。那么1≤y≤231−11 \le y \le 2^{31} - 11≤y≤231−1。要用浮点数表示y，最大的指数值只需要30即可。

怎么求出y的指数呢？

// y_exp 表示最高位的1所在的位值。
y_exp = 30 //先假设最高位的1在第30位。
while(!(y >> y_exp)) {
    y_exp--;
}

接下来我们求尾数M，怎么得到尾数呢？

因为尾数只允许有23位，多的就要舍去。我们先把前导1移到第31位， 前导1后面的就是精确表示这个数值的尾数。我们只能取其中的前23位。 所以，再右移8位，就得到了我们想要的23位尾数了。当然是需要&上一个mask的。 代码实现如下：

int frac_mask = 0x7fffff;
y <<= (31-y_exp);
frac = (y >> 8) & frac_mask;

接下来，我们就要对其进行舍入。 舍入规则详见float_half， 问题又变成了，什么时候需要加1。 需不需要加1,和被我们舍弃的掉最后8位有关。如果那8位数是大于0x80(10000000)的，必须加1, 如果正好是0x80000000也就是需要向偶舍入，只需看23位尾数的最后一位是奇数1还是偶数0,是1则要加1。

round = y & 0xff;
frac += ((round > 0x80) || (round == 0x80) && (frac & 1));

我们给frac加了1,如果溢出了，这种情况下，尾数位全位1。加1后，相当于1.f1.f1.f变成了10.f′10.f'10.f′了，为了变为原来的M的形式， 需要将小数点左移一位，指数加上1。此时，尾数只需要置0即可。

解题代码

unsigned float_i2f(int x) {
    int sign = (x >> 31) & 1, exp, frac, round;
    int frac_mask = 0x7fffff, x_exp;
    if (!x) return 0;
    if (!(x ^ (1 << 31))) return 0xcf << 24; // Handle the case of Tmin, which is -2^31, and its float representation is 0xcf000000
    if (sign) x = -x;
    x_exp = 30; // x_exp is the exponent of x in binary representation, which is the position of the highest set bit
    while(!(x >> x_exp)) {
        x_exp--;
    }

    exp = x_exp + 0x7f;
    x <<= (31 - x_exp); // Shift x to the left so that the highest set bit is at the 31st position
    frac = (x >> 8) & frac_mask; // Get the 23 bits after the highest set bit
    round = x & 0xff;
    frac += round > 0x80 || (round == 0x80 && (frac & 1));
    if (frac >> 23) { // If frac overflows, we need to adjust
        frac = 0;
        exp++;
    }
    return sign << 31 | exp << 23 | frac;
}

float_f2i

题目要求

  • 将双精度浮点数转化成整数
  • 参数作为无符号整数传递，被解释为双精度浮点数的位级表示，且第一个参数uf1表示的是低32位，第二个参数uf2表示的是高32位
  • 如果f超出整数能表示的范围，或者是NaN或Infinity，则返回0x80000000
  • 允许的操作符：任何整数/无符号整数操作，包括 || 和 &&，同时允许if条件语句和while循环语句。
  • 最大操作数：20

解题思路

我们知道双精度浮点数的表示：

  • 符号位：1位
  • 指数位：11位，偏移量位2^10 - 1 =1023。对于非规格化数，其指数位全为0,指数位1−bias1-bias1−bias=-1022。对于规格化数，其指数为 e−biase-biase−bias，其中e为指数位所表示的无符号整数值。
  • 尾数位：52位，对于非规格化数，尾数位0.f0.f0.f，对于规格化数，尾数为1.f1.f1.f

因为浮点数的尾数有52位，而int型整数只有31位精度，必然要进行截断，会有精度损失。

如果这个数的指数小于0,我们返回0即可。 一个int能表示的整数范围是[−231,231−1][-2^{31}, 2^{31} - 1][−231,231−1]，所以如果指数大于等于31,我们返回0x80000000即可。其中等于31时，正好 有可能表示的就是Tmin。

现在我们只需考虑规格化数中指数大于0且小于31的即可。

我们去取尾数值。尾数值要取uf2的后20位加uf1的前11位，再加上隐藏的前导1。 据此我们可以通过如下位运算得到尾数M。

unsigned M = ((uf2 & 0xfffff) <<11) | ((uf1 >> 21) & 0x7ff) | 0x80000000;

这样我们就得到了1xxxx...xxx(x取0或1)的位表示，其中1后面隐含了一个小数点。 我们来看这样一个例子

1.01100112×23=1011.001121.0110011_2 \times 2^{3} = 1011.0011_21.01100112​×23=1011.00112​我们要截断小数部分。实际得到的整数是101121011_210112​ 如果把1.011001121.0110011_21.01100112​用10110011210110011_2101100112​来表示，我们要得到最后的结果只需101100112>>4=1011210110011_2 >> 4 = 1011_2101100112​>>4=10112​这里做的是无符号整数的逻辑右移。 这里的4是怎么的来的呢？实际上我们是将前导1从第7位移到第e位，e为指数值，这里等于3。所以移动了7-3=4位。怎么来理解？ 1.01100112×231.0110011_2 \times 2^31.01100112​×23中最左边的1在最终结果里的权重就是232^323而这个1在101100111011001110110011的第7位。最终结果应该在第3位，所以移动了4位。

放到32位的位表示来说，要移动的位数就是(31-e)位。 所以

M >>= (31 - exp);

解题代码

int float64_f2i(unsigned uf1, unsigned uf2) {
    int sign = uf2 >> 31;
    int exp_mask = 0x7ff;
    int exp = ((uf2 >> 20) & exp_mask) - 1023;

    unsigned M = ((uf2 & 0xfffff) << 11) | ((uf1 >> 21) & 0x7ff) | 0x80000000;

    if (exp < 0) {
        return 0;
    }

    if (exp >= 31) {
        return 0x80000000u;
    }

    // In general, the leftmost bit of 1 's position index is equal to the exponent.
    // So we need to shift the significand to the right by (31 - exp) to get the integer value.
    M = M >> (31 - exp); // Shift the significand to the right that the highest set bit is at the exp-th position
    return sign ? -M : M;
}

float_negpwr2

题目要求：

  • 计算2.0−x2.0^{-x}2.0−x的浮点表示
  • 如果得到的结果太小以非规格化数都无法表示，返回0；如果得到的结果太大以至于无法表示成浮点数，返回+∞+\infty+∞。
  • 参数和结果都作为无符号整数传递，但它们应该被解释为单精度浮点值的位级表示
  • 允许的操作符：任何整数/无符号整数操作，包括 || 和 &&，同时允许条件语if和循环语句while
  • 最大操作数：20 首先我们来看浮点数能表示的范围。

单精度浮点数的指数偏移量位127,指数位的范围是[0,255][0,255][0,255]，对应的指数范围是[−126,128][-126,128][−126,128]。其中，指数位为0代表非规格化数， 指数位为255的数为NaN或者Inf,其他数为规格化数。

最小的非规格化正数位级表示为0x00000001，指数位为0,尾数为2−232^-{23}2−23，所以最小的规格化正数为2−126×2−23=2−1492^{-126} \times 2^{-23} = 2^{-149}2−126×2−23=2−149

所以任何满足−x<−149-x < -149−x<−149，即x>149x > 149x>149的数，都需要返回0作为结果。最大的规格化数为0x7f7fffff。对应的指数为127,尾数为2−2−232-2^-232−2−23， 所以最大的规格化数为2127×(2−2−23)=2128−21042^{127}\times (2 - 2^{-23}) = 2^{128} - 2^{104}2127×(2−2−23)=2128−2104。 在往上，就需要指数全为1的+∞+\infty+∞了。

即，对于任何满足 −x≥128-x \ge 128−x≥128，也即 x≤−128x \le -128x≤−128的数，都要返回inf。

当−x>−127-x > -127−x>−127，即x<127x < 127x<127，此时可以用规格化浮点数来表示。加上127的偏移即为指数位的数值。 剩下的情况是 127≤x≤149127 \le x \le 149127≤x≤149 此时可以用非规格化数来表示。

我们知道，非规格化数的指数恒为-126。2−x=2−126×2m2^{-x} = 2 ^ {-126} \times 2^{m}2−x=2−126×2m m等于126 - x，我们怎么利用尾数来表示 2126−x2^{126-x}2126−x呢？在23位的尾数中，最高位的1的权重为2−12^{-1}2−1需要将1左移22，即23+(−1)23 + (-1)23+(−1)位得到这个尾数的位表示。那么要表示 权重126−x126-x126−x则要将1左移23+126−x=149−x23 + 126 -x = 149 - x23+126−x=149−x位。

解题代码

unsigned float_negpwr2(int x) {
    // The smallest denormalized number is 2^-149, which has an exponent of -126 and a fraction of 2^-23.
    if ( x > 149) {
        return 0;
    }
    // The largest normalized number is 2^128 - 2^ 104
    if (x <= -128) {
        return 0x7f800000;
    }

    if ( x < 127) {
        return (-x + 127) << 23;
    }
    // For denormalized numbers, we need to shift the fraction to the left by (23 + 126 - x) = 149 - x
    return 1 << (149 -x);
}
