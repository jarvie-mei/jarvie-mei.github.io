14. 长代码和行号测试

unsigned float_half(unsigned uf) {
    unsigned sign = uf & 0x80000000;
    unsigned exp  = uf & 0x7f800000;
    unsigned frac = uf & 0x007fffff;

    if (exp == 0x7f800000) {
        return uf;
    }

    if (exp <= 0x00800000) {
        unsigned round = (uf & 3) == 3;
        return sign | (((exp | frac) >> 1) + round);
    }

    return sign | (exp - 0x00800000) | frac;
}

26. 长段落测试

MDX 和 Markdown 都非常适合写技术博客。普通段落不需要任何特殊语法，只需要直接输入文本即可。如果段落很长，浏览器会根据当前主题和屏幕宽度自动换行。这个部分可以用来测试正文的字体大小、行高、最大宽度以及移动端排版效果。

第二个段落用于测试段落之间的垂直间距。如果主题的 typography 配置正常，两个段落之间应该存在比较舒适的留白，而不是完全挤在一起。

27. 行内代码与公式混排

在 C 语言中，表达式 x << 1 表示左移一位。

对于一个 www 位整数，左移一位通常可以理解为乘以 222：

x≪1≈2xx \ll 1 \approx 2xx≪1≈2x

但需要注意溢出问题。

29. 自定义 React 组件测试
